How to run it?

1) ```brew install gradle```
2) ```gradle wrapper```
3) ```./gradlew assembleXCFramework```
4) ```brew install mint```
5) ```mint bootstrap && mint run xcodegen```
6) Open ParentalControl.xcodeproj in Xcode.
7) Run ParentalControlApp or ParentalControlAppMacOS.
